# Spanish verb data: sources

`es.json` and `js/spanish-common-verbs.js` are generated by
`scripts/build-spanish-verbs.js` from:

- Verb forms: conjugate-esp 2.3.6 by Jiri Mracek (MIT, notice below)
  https://github.com/jirimracek/conjugate-esp
- Used to check them: UniMorph Spanish, from English Wiktionary (CC BY-SA 3.0)
  https://github.com/unimorph/spa
- Common-verb ranking: FrequencyWords by Hermit Dave (CC BY-SA 4.0)
  https://github.com/hermitdave/FrequencyWords
